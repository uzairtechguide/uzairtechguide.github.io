What this tool does

This page turns spoken audio or video into a subtitle file in SRT format. The output is made for editors, creators, students, and anyone who needs captions for a clip, lecture, interview, podcast, tutorial, or social video.

The workflow is simple: add a Groq API key, choose a file, select a language if needed, and generate subtitles. The page then builds a subtitle file that can be downloaded and used in most modern players and editors.

This is a browser-based helper interface. It is designed to stay out of the way and focus on one job: creating subtitles cleanly, quickly, and with as little friction as possible.
What is Groq?

Groq is an AI infrastructure company known for very fast inference. In this tool, Groq is used to process audio transcription through the model selected in the request. That makes the subtitle generation fast and practical for everyday use.

People sometimes confuse Groq with Grok. They are not the same thing. Grok is a chatbot product from xAI, while Groq is the AI compute platform used here to run transcription requests. This page uses Groq for subtitle generation and not xAI Grok.

Because the transcription happens through Groq, you need your own API key. That keeps the page lightweight and lets the request go through your own access instead of forcing a separate account system into the website.

What are subtitles?

Subtitles are timed text that show what people are saying in a video or audio track. They help viewers read along with speech, understand accents better, follow fast dialogue, and watch in situations where sound is off or hard to hear.

Subtitles are not just for movies. They are used everywhere: tutorials, online courses, interviews, podcast clips, reels, shorts, documentaries, news videos, gaming content, product demos, and language-learning material.

SRT is one of the most common subtitle formats. It is plain text, easy to edit, and accepted by many video players and platforms. Each subtitle entry includes a number, a start time, an end time, and the subtitle text.

Where subtitles are used

Subtitles are used in two broad ways: for accessibility and for convenience. Accessibility helps viewers who are deaf or hard of hearing. Convenience helps viewers watching in noise, on mute, or in a language they are still learning.

How to import subtitles into a video

Importing subtitles means loading the subtitle file into a video player or editor so it appears during playback. In many apps, this is called adding captions, adding subtitles, or attaching a subtitle track.

In players like VLC, you usually open the video and then load the subtitle file from the subtitle menu. In editors such as DaVinci Resolve, Premiere Pro, CapCut, and Shotcut, you can import the subtitle file into the project timeline or media bin and align it with the video.

On YouTube, subtitles are usually uploaded through YouTube Studio as a subtitle track. On some platforms, you can either upload the subtitle file directly or paste the text into a subtitle editor.

Tip: when importing, make sure the subtitle file name is easy to find and the subtitle timing matches the correct video version. A subtitle file made for one cut of a video may not align well with another cut.
How to burn subtitles into a video

Burning subtitles means permanently rendering the subtitle text into the video itself. That is different from soft subtitles, which can be turned on or off. Burned subtitles are visible in every player because they become part of the video image.

Burning is useful when you want subtitles always visible, especially for social media uploads, reposts, or exports where the player may not support separate subtitle tracks. It is also handy when you want the text style to remain the same everywhere.

You can burn subtitles in editors like CapCut, Premiere Pro, and DaVinci Resolve by importing the subtitle file, placing it on the timeline, and exporting the video. With FFmpeg, subtitle burning is possible through command-line rendering as well.

Example concept: a video file plus an SRT file can be merged during export so the final rendered video includes the text on screen permanently. That is often called hardcoding subtitles.

How to convert video to MP3

Sometimes the easiest way to work with a video is to extract only the audio. That can reduce file size, speed up uploads, and make transcription easier if the video contains only spoken dialogue.

You can convert a video to MP3 using tools like VLC, FFmpeg, Audacity, HandBrake, or any reliable editor that supports audio export. The goal is to keep the speech while removing the video stream.

Why do this? Smaller audio files can upload faster, especially on mobile or weak internet. If a video is too large for the 25MB limit, extracting the audio and exporting it at a lower bitrate can be the simplest fix.

Good practice: preserve speech clarity. Do not over-compress the file so much that voices become distorted. A smaller file is useful only if the words are still understandable.

How to reduce a file under 25MB

If your file is larger than 25MB, the most practical fix is to trim, compress, or convert it before uploading. This is not a bug in the page; it is a real API-side limit for the transcription flow used here.

  • Trim unnecessary sections: remove long intros, silence, or outro music.
  • Lower the video bitrate: smaller bitrate often means much smaller file size.
  • Extract audio only: converting to MP3 can cut the size dramatically.
  • Split long recordings: separate a lecture or podcast into multiple clips.
  • Use efficient codecs: modern audio codecs often provide better quality per byte.

Frequently asked questions

Why does it error out when the file is larger than 25MB?

The transcription flow used by Groq in this setup does not accept files above the 25MB limit. That is why uploads beyond that size fail. The fix is to trim the file, compress it, convert video to MP3, or split it into smaller parts before uploading.

Is the 25MB limit a website bug?

No. It is a service limitation for the transcription request path. The page is built to respect that limit instead of pretending it does not exist.

Can I use this for long lectures?

Yes, but long lectures may need to be divided into segments so each upload stays under the size limit. Splitting by topic or chapter also makes editing easier later.

What subtitle file does this generate?

This tool generates .srt files, which are simple, common, and compatible with many editors and players.

Can I edit the subtitle file after download?

Yes. Because SRT is plain text, you can open it in a text editor and adjust the wording, timing, or numbering if needed.

Why is auto-detect sometimes better than choosing a language?

Auto-detect is useful when the audio contains mixed speech, code-switching, uncertain accents, or multilingual segments. Manual language selection is better when the content is clearly in one language.

Can subtitles improve search or discoverability?

Yes. For creators, subtitles often help with indexing, accessibility, and viewer retention because more people can understand the content quickly.

Troubleshooting

The Generate button is disabled

That usually means one of the required inputs is missing. Add a valid Groq key and select a file. Once both are in place, the button should become active.

The upload is slow

Large files, poor connection, or mobile data can slow things down. Try a smaller file, a stronger network, or a shorter clip if you need quicker results.

The subtitles look off

That can happen when the audio is unclear or when the wrong language is selected. Try auto-detect first, then test the most likely language for the content.

The file is under 25MB but still fails

Check for a broken upload, unsupported audio encoding, unstable internet, or a temporary API-side issue. Re-exporting the file to MP3 or WAV often fixes strange edge cases.

The subtitle file downloads but looks empty

That can happen if the source has no clear speech or if the transcription response contains almost no text. Try a different source file or a section with better spoken audio.

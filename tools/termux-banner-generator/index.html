1
Save the script

Download the .sh, then move it into Termux: mv ~/storage/emulated/0/downloads/termux_banner.sh ~/.termux_banner.sh Run termux-setup-storage first if the downloads folder is missing.

2
Make it run

Run chmod +x ~/.termux_banner.sh then paste the .bashrc snippet at the end of ~/.bashrc

3
Test it

Open a new session, or run source ~/.bashrc. The banner should appear.

Frequently asked questions

Why does root need its own marker?

Some info, like CPU temperature or your root UID, lives in files that only root can read. Those rows run through su. Each login will then ask Android for root permission, so expect a prompt every time you open a session unless your root manager remembers the choice.

What does the root guard do?

With the guard on, root rows only run when the su binary exists. On a non-rooted device the row is skipped, and the rest of the banner still shows. It does not check whether you are actually granted root.

Why does the default welcome text still show?

Termux prints its MOTD file before .bashrc runs. To hide it, empty the file: : > $PREFIX/etc/motd. Back it up first if you want the original back.

Some rows show nothing. Why?

Commands like the Wi-Fi IP depend on interface names, and battery needs the Termux:API app plus its package. Test a command in the terminal first. If it prints nothing there, it will print nothing in the banner.

Your settings stay on this device

Your banner settings are saved in this browser's local storage so the editor reopens as you left it. Nothing is sent to any server. Use Reset to clear them.
